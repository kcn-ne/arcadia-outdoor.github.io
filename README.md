# ARCADIA — Outdoor Gear

> **The journey is yours.**

ARCADIA is a premium outdoor storefront concept built around the journey rather than a generic product grid. It combines field photography, curated gear, journey-based navigation, editorial notes, and a rugged-but-refined visual identity.

## What makes this version different

- **Shop by Journey** instead of only product categories.
- **Field Notes** for useful outdoor content.
- Editorial photography and product photography are stored locally.
- Dark forest, warm sand, stone, and sunset-orange palette.
- LocalStorage demo for saved gear and an adventure cart.
- Responsive layouts designed for GitHub Pages.
- Product detail pages, collections, category pages, support, policies, and 404 experience.

## Visual direction

ARCADIA is intentionally not another soft pastel ecommerce template. The visual system uses cinematic mountains, rugged gear, editorial typography, generous whitespace, forest green, warm neutrals, and controlled orange accents.

## Main routes

- `index.html` — homepage
- `shop.html` — full catalog
- `journeys.html` — shop by journey
- `collections.html` — curated kits
- `field-notes.html` — outdoor editorial section
- `backpacks.html` — backpacks
- `camping.html` — camping
- `footwear.html` — footwear
- `product.html?id=1` — dynamic product detail
- `saved.html` — saved products
- `cart.html` — local demo cart
- `contact.html` — support

## Technologies

HTML5 · CSS3 · Vanilla JavaScript · WebP · LocalStorage · GitHub Pages

## Assets

All storefront photography used by the project is stored locally under `assets/`. Product assets are individual files so each card can be controlled independently. The logo is also local and optimized for web use.

Before commercial use, verify licensing and usage rights for every final image, logo, product design, font, claim, and third-party asset.

## V2 Image Refinement

V2 replaces product and editorial imagery that contained visible branding, embedded typography, inconsistent framing, or overly aggressive crops. The 12 catalog products now use distinct text-free images matched to their actual product names, while the editorial cards use clean landscape photography without words or interface elements. Product cards and product detail views use contain-style presentation so the complete item remains visible.

## V3 Image Correction

V3 rebuilds the storefront photography presentation so every featured product uses an individual square image with the subject fully framed. Category tiles now use separate lifestyle photography rather than reusing product or hero imagery. Images are stored locally, contain no embedded marketing copy or brand marks, and are presented without unnecessary padding or forced cropping.
